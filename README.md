# Seminarkurs Hochregallager
Der Seminarkurs beinhält eine Wiederbelebung & Aufrüstung eines alten automatischen Lagersystems hinzu einem optimiertem Lagersystem mit einem intelligenten Managementsystem. (oder auch Retro-Fit von intelligentem Lagersystem)
## Pflichtpunkte
- Analyse und Dokumentation des bestehendes Modells
- Überprüfung der bestehenden Hardware & gegebenenfalls einen Austausch
- Manuelle Positionierung
- Automatische Positionierung auf Knopfdruck
- Automatisches Ein-&Ausladen der Be-&Entladeeinheit (Automatische Einlagerung)
- Instandsetzung der Bepack&Entladestation, unter anderem des Scanners
- Optimierung der Lagerbelegung mittles KI
- Implementierung eines Webseiten Interfaces, zur Steuerung und Sichtung des Lagerbestandes
- Evtl Kameraerkennung der Objekte und Automatischer Zuordnung
